# MacEase（マッキーズ）

[English](README.md) | 日本語

MacEase は、Finder の右クリックメニューから選択したファイルを変換・圧縮・編集するアプリです。変換や編集の結果は、初期設定では新しいファイルとして保存します。元のファイルを置き換える設定もあり、その場合は元のファイルをゴミ箱に移し、「取り消す」で戻せます。

処理は Mac 上で行います。更新の確認には GitHub に接続します。Apple の一部の機能には、言語データやモデルのインストールが必要です。

## 機能

- **画像:** リサイズ、圧縮、回転、反転、余白のトリミング、背景の編集、メタデータの削除、テキスト認識、アイコンや AppIcon セットの書き出し。対応する画像を PNG、JPEG、HEIC、WebP、AVIF、JPEG XL、GIF、TIFF、BMP、ICO、ICNS、SVG、PDF に変換できます。TGA への変換は、ImageIO が読み込みと書き込みに対応する環境で表示されます。PSD は保存済みの合成画像から PNG、JPEG、TIFF を書き出し、レイヤーを持つ元のファイルは保持します。読み込みに対応するカメラ RAW も元のファイルを保持します。SVG はパスのトレースか PNG の埋め込みを選べます。
- **動画:** リサイズ、トリム、圧縮、回転、反転、フレームレートの変更、音声の削除。対応するストリームを MP4、MOV、M4V、MKV、WebM、AVI、FLV のコンテナ間で変換できます。GIF、アニメーション WebP、APNG、サムネイル、音声や、背景を透明・単色・ぼかしにした動画を書き出せます。音声抽出は AAC または ALAC の M4A にも対応します。
- **HDR から SDR:** 対応する HDR 画像や動画を **変換 > SDR** で変換します。アプリが内容を確認し、SDR の入力はスキップします。画像は単一画像の JPEG、HEIC、AVIF、JPEG XL、PNG に対応します。動画は互換性のある MP4、MOV、M4V に対応し、対応条件を満たす Dolby Vision 8.4 のベースレイヤーも扱います。
- **音声:** MP3、AAC または ALAC の M4A、コンテナなしの AAC、WAV、AIFF、FLAC、Ogg Vorbis、Opus、PCM または ALAC の CAF を変換できます。AIFF-C の読み込みはコーデックに依存します。圧縮、ラウドネスの正規化、トリムもできます。
- **字幕:** Apple のオンデバイスの Speech・Translation フレームワークを使い、音声や動画から SRT、WebVTT、プレーンテキストを生成したり、翻訳した SRT を書き出したりできます。
- **PDF:** 結合、分割、ページ抽出、回転、圧縮、テキストの書き出し。各ページを PNG・JPEG としてフォルダ内や PDF の隣に保存するか、1 つの複数ページ TIFF に書き出せます。スキャンされた PDF のテキスト書き出しには OCR を使います。
- **文書とテキスト:** 下表のとおり、リッチテキスト文書の書き出し、HTML・Markdown の描画、構造化テキストや既存の字幕ファイルの変換ができます。文字コードを UTF-8、BOM 付き UTF-8、UTF-16、Shift_JIS に変更したり、改行コードを統一したりできます。JSON は整形、空白の除去、キーの並べ替えに対応します。並べ替えでは比較方法、昇順・降順、優先するキー、単純な値の配列を並べ替えるかを指定できます。
- **フォルダ:** 内容のリネーム、検証済みの重複ファイルや空フォルダの削除、フォルダツリーのコピー・保存、容量の分析。重複ファイルは、初期設定では残すコピーを毎回確認します。更新日時が最も古いコピーか新しいコピーを残し、残りを自動でゴミ箱に移す設定もあります。サイズ、空ファイル、名前、更新日時で候補を絞れます。コピーはバイト単位で比較し、少なくとも 1 つを保持します。
- **レポートと除外設定:** 分析では選択したフォルダを 1 つのレポートにまとめ、CSV、JSON、HTML、プレーンテキスト、Markdown で書き出せます。フォルダ名、ファイル名、拡張子の除外ルールを、すべてのフォルダ走査または個別の機能に適用できます。
- **アーカイブとユーティリティ:** フォルダから ZIP、7z、TAR、tar.gz を作成し、ZIP、7z、TAR、gz、bz2、xz、RAR を展開できます。同梱の CFR とインストール済みの Java ランタイムで JAR をデコンパイルできます。SHA-256、MD5、SHA-1、SHA-512 のチェックサムも計算できます。
- **Apple Intelligence:** 画像や PDF の内容に基づく名前をプレビューして確定したり、言葉で指定した依頼を、対応する画像・動画・音声操作の実行計画に変換したりできます。
- **プリセット:** Discord、X、Instagram、LINE、メール、Web 向けの同梱設定を編集できます。これらはアプリの初期値であり、各サービスの現在のアップロード上限を保証するものではありません。

文書とテキストの変換メニューには、次の出力先があります。

| 入力 | 出力 |
| --- | --- |
| DOCX、ODT、RTF、RTFD | PDF、TXT |
| HTML | ソースの TXT、描画結果の TXT、PDF |
| Markdown | ソースの TXT、HTML、PDF |
| CSV | TXT、JSON、XML、HTML、Markdown |
| JSON | TXT、CSV、XML、XML またはバイナリの plist、YAML、TOML |
| XML | TXT、JSON |
| INI、CFG、CONF | TXT、JSON、XML |
| YAML、TOML | TXT、JSON |
| XML またはバイナリの plist | JSON |
| SRT、WebVTT | ソースの TXT、もう一方の字幕形式 |
| その他の認識可能なテキストファイル | TXT。ただし、すでに TXT に分類されるファイルを除く |

文書の書き出しは基本的なリッチテキストの再配置を行うため、Office 文書のレイアウトが変わる場合があります。HTML の描画ではスクリプトと外部リソースを遮断し、PDF は連続した 1 ページに書き出します。Markdown は生の HTML と安全でないリンクを省きます。構造化テキストの変換ではコメントや書式が失われる場合があり、対応しない値の変換はエラーになります。JSON から CSV への変換には、入れ子のないオブジェクトの配列が必要です。字幕変換はプレーンテキストの範囲に対応し、未対応の装飾やメタデータはエラーになります。これらの書き出しでは、どちらの出力モードでも元のファイルを保持します。

画像変換では、アニメーションのフレームや TIFF のページを失う変換を拒否します。新しい画像ファイルで透明度や HDR を保持できない場合、対応する処理では指定した背景色で合成するか SDR にトーンマッピングし、警告を表示します。画像編集や形式変換で置き換える場合は、意図しない透明度や HDR の喪失を拒否します。明示的な **変換 > SDR** は選んだ出力モードに従います。動画の編集は、どちらの出力モードでも、複数の映像・音声トラックや保持できないストリームがある入力を拒否します。明示的な書き出しは元のファイルを保持し、省略するストリームを知らせます。コンテナに対応していても、その中のすべてのコーデックを扱えるわけではありません。

SDR から HDR への変換、WMA、AV1 動画のエンコード、RAR の作成は未実装です。画像・動画・音声の操作は選択したファイルを対象とし、フォルダ内のメディアを走査しません。

[docs/SPEC.md](docs/SPEC.md) は目標とする製品の仕様を記載しています。すべての対応 macOS バージョンで検証済みではない受け入れ基準も含みます。

## 動作環境

- Apple シリコン搭載の Mac、macOS 26 以降。
- 右クリックメニューには MacEase の Finder 拡張機能の有効化が必要です。
- AI 機能には Apple Intelligence の有効化とオンデバイスモデルの利用準備が必要です。ほかの操作に Apple Intelligence は必要ありません。
- 文字起こしには対応する Speech の言語データ、字幕翻訳には Translation のモデルがインストールされている必要があります。不足している場合は MacEase が知らせます。
- JAR のデコンパイルには、macOS が検出できる Java ランタイムが必要です。

## インストール

1. [Releases](https://github.com/TKY-27/MacEase/releases/latest) から `MacEase-<version>.dmg` をダウンロードし、リリースページの SHA-256 チェックサムと一致するか確認します。
2. DMG を開き、**MacEase** を **アプリケーション** にドラッグします。
3. MacEase を開きます。Apple の公証を受けていないため、初回は macOS に起動をブロックされます。
4. **システム設定 > プライバシーとセキュリティ** を開き、下までスクロールして MacEase の横にある **このまま開く** をクリックし、確認します。
   または、ターミナルで次を実行します。
   ```sh
   xattr -dr com.apple.quarantine /Applications/MacEase.app
   ```
5. ようこそウインドウで Finder 拡張機能を有効にします。完了通知が必要なら通知を許可し、**完了** をクリックします。

リリースビルドは自己署名証明書で署名しており、Apple の公証は受けていません。ソースからビルドすることもできます。

## 使い方

1. Finder でファイルやフォルダを選び、右クリックして **MacEase** を選びます。1 種類のファイルだけを選ぶと操作が直接表示され、複数の種類を選ぶと種類と件数でグループ化されます。
2. プリセットや形式を選ぶとすぐに実行します。**反転** は **回転** の中、アニメーションの書き出しは動画の **変換** の中にあります。HDR の変換は **変換 > SDR** です。**カスタムサイズ…** は **サイズ変更** と **圧縮** にだけ表示されます。ほかのウインドウは、必要な入力、削除の確認、結果の表示に使います。PDF の結合と複数画像からの PDF 作成では、ページ順を調整するウインドウが開きます。
3. 開始から 0.8 秒後も実行中の処理は、Finder のフォーカスを奪わずにアクティビティウインドウに表示されます。**停止** で処理をキャンセルできます。ウインドウを閉じても処理は続きます。フォルダ走査の進行状況もここに表示されます。
4. 初期設定では、問題なく完了した処理は自動で閉じます。アクティビティが表示されている場合、警告、スキップ、失敗した項目は残ります。結果がそこに残らない場合は、通知が有効なら完了通知を表示します。利用可能な場合は **Finder で表示** や **取り消す** を選べます。最近の処理はメニューバーにも表示されます。

**設定 > 一般 > 変換または編集時** で、**新しいファイルとして保存** か **元のファイルを置き換える** を選びます。新しいファイルは元のファイルの隣に保存し、名前が重複する場合は番号を付けて上書きを避けます。置き換えでは、出力を検証してから元のファイルをゴミ箱に移します。書き出しや抽出では常に元のファイルを保持します。「取り消す」は作成した出力をゴミ箱に移すか、置き換えた元のファイルを戻します。変更されたファイルや、ゴミ箱から失われた元のファイルはスキップする場合があります。完全削除には確認が必要で、取り消せません。

<img src="docs/images/compress-ja.png" width="420" alt="圧縮のカスタムサイズパネル（目標 10 MB）">

メニューバーのアイコンから **設定** を開きます。サイドバーには **Finder メニュー** とファイルの種類ごとのページがあります。**Finder メニュー** ではプリセット・形式ごとの表示、リサイズや圧縮の数値、追加の回転角度、プラットフォーム別プリセットを編集できます。一部の形式やユーティリティは初期設定で非表示です。ほかのページで品質、背景、アニメーション、音声、字幕、OCR、PDF、フォルダ、テキストの既定値を設定します。**詳細 > すべての設定をリセット…** は履歴と編集済みのプラットフォーム別プリセットを保持します。MacEase を再度開くと、セットアップが完了するまではようこそウインドウ、その後は設定が開きます。

## ソースからビルドする

必要なものは、Apple シリコン搭載の Mac、macOS 26 以降、Xcode 26 以降、Homebrew です。macOS 27 専用の機能をビルドするには Xcode 27 が必要です。

```sh
git clone https://github.com/TKY-27/MacEase.git
cd MacEase
make bootstrap
make build
make test
```

初回起動の前に、`build/DerivedData/Build/Products/Debug/MacEase Dev.app` を `~/Applications` または `/Applications` にコピーしてください。このどちらにもない場合、ようこそウインドウを完了できません。Finder 拡張機能は、ようこそウインドウか **システム設定 > 一般 > ログイン項目と機能拡張** から有効にできます。

詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

## 仕組み

サンドボックス化された Finder Sync 拡張機能が、メニューバーアプリの書き出したカタログから右クリックメニューを作ります。選択した操作とファイルパスは、トークンで検証する URL スキームでアプリに渡します。アプリは処理を実行し、入力パネル、アクティビティ、設定を表示します。`Packages/MacEaseKit` には `MenuCatalog`、`Engine`、`Formats` があります。

文書、画像、メディア、OCR、音声認識、翻訳には Apple のフレームワークを使います。同梱の Swift パッケージ依存関係には、Markdown 用の **swift-cmark** と、libyaml を含む YAML 用の **Yams** があります。TOML には同梱の **toml++** を、メモリの所有権を管理する C ブリッジ経由で使います。ほかの形式は、libwebp、libavif、libjxl、libvpx、libopus、libarchive などの許諾条件が緩やかなライブラリと、MP3・GIF エンコーダ、Matroska・WebM コンテナ、SVG トレースなどの独自実装で扱います。

詳細は [docs/SPEC.md](docs/SPEC.md) と [docs/adr/](docs/adr/) を参照してください。
