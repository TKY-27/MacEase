functional/specification, safety/concurrency, consistency, and final regression
and release readiness. The last two completed reviews reported no unresolved
Critical or High findings. All seven material Medium findings were fixed:

- Duplicate directory identity and overlapping exports.
- Bounded hierarchy depth and retained path storage.
- Failed-preview staging leases.
- Central-directory limits before libarchive allocation.
- Repeated archive scans during multiple-member export.
- Implicit AppleDouble expansion.

The final review also checked the subsequent window content-size correction and
found no actionable issue. An interrupted review attempt is not counted; its
preliminary ZIP tail ambiguity finding was corrected and regression-tested.

Terminal enumeration of an app-created item-replacement directory is denied by
macOS access protection. Its removal was verified by `lstat` returning ENOENT,
not by interpreting a failed directory listing as empty. Independent session
tests and benchmarks verify that unselected members are not materialized.

## macOS 26 VM

The existing VM runs macOS 26.6.2 (25G83). Upgrade, strict signature verification,
and Finder extension enablement pass. Finder browsing, search, and distinct
duplicate-name previews were verified with the earlier signed candidate. The
latest candidate installs and launches successfully.

Final visual acceptance is incomplete: automated mouse input does not reliably
release through Screen Sharing, and the native VM display also fails to forward
clicks consistently. A sampled wait was in AppKit mouse tracking, not archive
decoding. These input failures are not evidence of an application failure.

## Performance

See `docs/spikes.md` for measured workloads and limitations. Standard SVG bytes
are unchanged; no SVG speedup is claimed. The 1,024-empty-member ZIP export
fixture improves from a 1.966-second median to 0.105 seconds by sharing a single
archive reader. Listing, preview, and close medians are 9.511, 6.245, and 0.591 ms.
These are standalone Release Engine measurements, not whole-app memory bounds.
