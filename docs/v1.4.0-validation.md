## Performance and presentation limits

See `docs/spikes.md` for the paired optimized Engine measurements. Warm photo
updates improve materially by retaining bounded source renditions. Cold photo
preparation and process peak RSS increase. Exact video seek measurements do
not establish a speedup; native composition preparation adds initial work.
The interactive cropped preview differs by one raster row in the comparison,
while settled dimensions match; preview resampling is not pixel-identical.
Full-resolution/HDR export checks remain separate from preview measurements.

Code inspection identified playback-time player-view creation and redundant
precise seeking in the previous UI. Both paths were removed. Sampled native
play/resume screenshots show visible video, but the original brief blackout
was not captured with temporal instrumentation. No measured blackout duration,
whole-app startup latency or universal zero-dropped-frame claim is made.

## Independent reviews

Fresh GPT-6.1 Sol/high contexts reviewed editor, archive and complete diffs.
Multiple rounds fixed selected-occurrence splitting, boundary frame stepping,
final frames at high speed, destination filesystem aliases, split-selection
deduplication, and missing-input recovery. The final whole-diff review and
limited verification of subsequent fixes report no unresolved P1/P2 findings.
Actual UI inspection additionally corrected HatchZip Stop/Cancel labels to
Pause, with matching Japanese help and accessibility text. GUI Pause/Resume
then completed all 6,000 independently hashed files.

## Remaining limits

- UNVERIFIED, OWNER-EXCLUDED: actual VoiceOver operation and macOS 26 VM
  visual interaction. The owner explicitly extended these two exclusions to
  v1.4.0 on 2026-10-30 (ADR 0042); neither is reported as passed.
- Real File Provider/network destructive execution is intentionally refused;
  API/path refusal is covered, not destructive cloud-provider behavior.
- Only one source video is editable. Multi-file import, multiple tracks,
  transitions and audio fades are outside this release.
- No exhaustive every-format/every-control cross-product is claimed.
- Release signing uses the existing self-signed identity; Apple notarization
  is outside the established distribution process.
