## Organization quality and performance

A predeclared synthetic English/Japanese corpus matched 20/20 expected outcomes:
8 clear texts, 2 PDFs, 2 rendered-text images and 8 empty/unknown held cases.
Median complete classification was 1.251 seconds; maximum 1.698 seconds. An
initial 14/16 result exposed unsupported categorization of meaningless text.
The structured response now explicitly declares whether content supports its
category; unsupported suggestions are held without renaming. Four independent
unknown examples were added before the final run. This small result is not a
real-world accuracy guarantee. Video/audio classification quality was not part
of that corpus. Some model-written hold reasons can contain English text.

Classification and policy output budgets are 256 and 512 tokens. A previous
unbounded probe took 188.784 seconds and failed with a model context error;
no final bounded case timed out. Content and model calls stayed on device.

A ten-second standalone probe using the production watcher measured below
0.003% of one CPU core both without a watcher and with one idle watcher.
This is below useful resolution for claiming an improvement. It excludes the
full app, inference, stability scans and large folder sets.

Three paired optimized API runs use the same SDK, fixtures and native playback
path for baseline and candidate. Median first-ready times (baseline/candidate)
are 110.24/106.44 ms for a 24MP photo, 159.66/161.26 ms for 1080p video and
325.31/201.35 ms for 4K video. Peak RSS is 171.56/171.59, 94.72/94.84 and
144.23/143.47 MiB respectively. Independently decoded comparison PNGs match in
dimensions and every RGB value. Driver and cold-cache variation prevents a
speedup claim. These are source/preview API measurements, not full-app memory.
Warm photo adjustment medians at 960px are 2.552/1.990 ms and at 1600px
4.782/4.816 ms. Video frame retrieval medians are 25.807/25.540 ms at 1080p
and 229.101/202.187 ms at 4K. These use AVAssetImageGenerator, not timed
native-player UI seeking.

Three paired exports of the same six-second, two-segment source (second segment
at 1.5x, 360p, slight exposure adjustment) took median 471.751/476.014 ms.
Ranges overlap: 462.696–481.012/462.666–476.780 ms. All six outputs fully decode
as 640x360 H.264 at 30 fps with continuous video/audio timestamps and unchanged
original hashes. Both versions produce 151 frames (5.033333 seconds) and
240,000 audio samples at 48 kHz (5 seconds); final-frame rounding is unchanged.
No export speedup is established.
