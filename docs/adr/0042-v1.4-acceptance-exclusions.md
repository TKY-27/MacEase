# 42. v1.4 acceptance exclusions

Date: 2026-10-30
Status: Accepted

## Context

The earlier VoiceOver and macOS 26 VM acceptance exclusions do not automatically
extend to v1.4.0. The signed release candidate has completed physical macOS 27
checks, local build, lint, tests, native archive verification and independent
reviews. Actual VoiceOver operation and macOS 26 VM visual interaction remain
unverified in the available environment.

## Decision

The owner explicitly excludes these same two checks from the v1.4.0 publication
gates and authorizes publication after the remaining checks. Record both as
unverified, never passed. All other acceptance requirements remain unchanged.

Retain the existing disabled GitHub Actions setting and release signing identity.
Build the final DMG from the tagged commit and verify the public downloads,
checksum and latest-release API after publication.

## Consequences

Local evidence and the two exclusions accompany the release. This decision does
not establish VoiceOver usability or macOS 26 visual acceptance, waive observed
failures, or extend the exclusions to future releases automatically.
