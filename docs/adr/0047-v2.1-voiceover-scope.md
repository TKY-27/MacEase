# 47. Version 2.1 VoiceOver scope

Date: 2026-11-02
Status: Accepted

## Context

Some editor, comparison and settings controls had verified VoiceOver captions.
The individual Retry button's spoken label remained unverified despite its
working keyboard focus and activation. Host and VM capture limitations blocked
that remaining observation. No unavailable check was recorded as passed.

## Decision

On 2026-11-02 the owner explicitly removed VoiceOver support from the requested
scope and instructed that further VoiceOver work was unnecessary. MacEase 2.1
does not claim VoiceOver support, and VoiceOver verification is no longer a
release gate. Stop that testing and restore all temporary reader settings.
This is a new owner decision, not an extension of an earlier release waiver.

Keep existing native control semantics and labels. Keyboard operation, focus,
visual checks, the macOS 26 VM smoke check, compression quality, latency,
actual-app memory and the remaining release requirements continue to apply.
Publication stays on hold until those requirements pass.

## Consequences

Preserve previously observed accessibility evidence and mark remaining speech
checks unverified and outside the supported scope. Do not describe those checks
as successful or remove otherwise useful native accessibility behavior.
