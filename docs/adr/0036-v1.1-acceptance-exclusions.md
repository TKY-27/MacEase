# 36. v1.1 acceptance exclusions

Date: 2026-10-26
Status: Accepted

## Context

Implementation, local tests, independent reviews and signed candidate packaging
are complete. Publication was held for actual VoiceOver operation and the final
macOS 26 VM visual check. The owner states that these checks are unavailable in
their environment and explicitly requests their removal from mandatory
acceptance so final publication can proceed.

## Decision

Exclude those two manual checks from the v1.1.0 release gates. Record them as
unverified and owner-excluded, never as passed. Retain the completed physical-Mac
checks and earlier VM observations without extending their coverage claims.

Keep all other requirements, including the independent reviews, local tests,
source retention and Undo checks, signed packaging, existing Finder extension
permissions, bundled licenses, SHA-256, and anonymous download verification.
GitHub Actions remains disabled. Build from the final tag commit and publish
the DMG and checksum without replacing existing tags or release assets.

## Consequences

The two unavailable manual checks no longer block v1.1.0 publication. The
release record retains their coverage limitations. No application behavior,
accessibility implementation, automated test, or signing policy changes.
