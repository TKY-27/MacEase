# Bundled media tools

MacEase remains MIT licensed. Its media download and local MP3 workflows launch independent
third-party executables from `Contents/Resources/media-tools/bin`. It does not
link FFmpeg into the MacEase app. Local MP3 encoding streams PCM through a pipe
into libmp3lame, with no automatic fallback or intermediate audio file.
These executables retain their upstream licenses. GPL and nonfree FFmpeg
features are disabled. LGPL FFmpeg and LAME are the isolated executable exception
recorded in SPEC sections 22–23 and ADRs 0052–0053.
Gallery downloads use the unmodified GPL-2.0-only gallery-dl command-line
program as a separate process (ADR 0057). Its implementation is neither linked
nor copied into the MIT application. Its exact source, license and required
Requests dependencies are included in the matching source distribution.

## Build

On an Apple Silicon Mac with Xcode command line tools, CMake, Meson, Ninja and
pkg-config:

```sh
scripts/build-media-tools.sh
```

The script verifies every archive against `Vendor/media-tools.lock`, then builds
CPython, OpenSSL, FFmpeg, LAME, libvpx, dav1d, Opus and QuickJS-NG from the exact pinned sources.
QuickJS-NG uses a static arm64 solver-only CLI from its pinned MIT-licensed
engine source. The stock CLI and `quickjs-libc` are not linked.
yt-dlp is installed from its
Unlicense Python source distribution, rather than its GPL-containing macOS
standalone executable. The pinned EJS wheel contains offline solver JavaScript;
its matching source distribution is included. Native executables and extensions omit debug and local symbols before signing;
external symbols remain available for dynamic loading. No package manager or
external Python is required at runtime. Python's TLS verifier uses macOS's
`/etc/ssl/cert.pem`; OpenSSL and Python do not need Homebrew libraries.

Python intentionally omits interactive, database, Tk, ctypes, LZMA and Zstandard
optional modules. It also omits idlelib, tkinter, turtledemo, ensurepip, certifi
tests and generated bytecode caches. Python source and the remaining extension
modules are retained; `-B` prevents new bytecode writes. Download requests use
the included standard urllib backend.
The host uses `python3 -I -B -m yt_dlp`, ignores user configuration and plugins,
passes explicit QuickJS and FFmpeg paths, and never self-updates these tools.
Image galleries use `python3 -I -B -m gallery_dl` with configuration discovery,
postprocessors and interactive authentication disabled. Only supported image
files are accepted; downloads are verified before publishing a new folder.
`MacEase Source.json` records the requested gallery page, retrieval time and saved
filenames. This records a download origin, not authorship or authenticity.

FFmpeg uses native VideoToolbox H.264 and AAC encoders, VP9 through libvpx,
AV1 decoding through dav1d, Opus through libopus, MP3 through libmp3lame, and
native PCM/FLAC encoders. HTTPS and encrypted HLS use the macOS Secure Transport
TLS backend, without linking FFmpeg to OpenSSL.
FFmpeg and LAME are shared libraries with relative install names. Users can
replace these independent tools with compatible modified builds. Signing
replacement executables ad hoc can be necessary under macOS code validation.
No MacEase source object relinking is needed.

QuickJS-NG 0.18.0 replaces Node. The pinned yt-dlp 2026.10.26 supports
QuickJS 2023-12-09 or newer and every QuickJS-NG release; its recommended
performance floors are QuickJS 2025-04-26 and QuickJS-NG 0.12.0.
EJS 0.8.0 remains bundled, with remote components disabled. There is one explicit
runtime and no fallback. QuickJS-NG needs no JIT entitlement under Hardened Runtime.
The stock CLI exposes host I/O through native modules. MacEase instead applies
`Vendor/patches/quickjs-solver-only.patch` and supplies `quickjs-solver.c`.
The C entrypoint accepts only `--script FILE`, `--help` and `--version`.
It reads and closes the caller-selected script before evaluating any JavaScript.
The only installed host callback is `console.log`; ordinary language intrinsics,
base64, promises and clocks remain available. There are no JavaScript file,
environment, process, worker or network APIs, no `std`/`os`/`bjson` modules,
and no loader for other files or URLs. Dynamic imports always reject. Static
imports are syntax errors in the forced script mode; `--std` is rejected.
The trusted Python process retains download and staging access.

This is an API capability boundary, not an OS process sandbox. It does not
protect against native engine vulnerabilities, CPU exhaustion or memory exhaustion.
No wrapper process, sandbox profile or additional entitlement is required.

The pinned provider embeds the EJS library, core, player string and challenge JSON
inside one script, ending with `console.log(JSON.stringify(jsc(...)))`.
It launches `qjs --script TEMPFILE`, supplies no stdin content, and parses stdout
as JSON. A nonzero exit or nonempty stderr is a provider failure. The solver
needs no module loading or host API beyond its final console output.

The pinned provider creates a mode-0600 JavaScript file using Python's
`NamedTemporaryFile` and unlinks it in `finally`. `MediaToolProcess` sets `TMPDIR`
to the per-analysis or download staging directory. Cancellation removes the
whole staging directory, including a script left by a killed provider.

On 2026-11-24, Node and QuickJS-NG both solved challenges and downloaded format 18
for `jNQXAC9IVRw`, `aqz-KE-bpKQ` and `M7lc1UVf-VE`, with matching SHA-256 hashes and nonempty audio/video packet streams.
No temporary JavaScript files remained. Solver timings exclude network and media
transfer: `time.perf_counter()` surrounds the upstream provider's

## Isolation verification

`make test` and the media build run `scripts/verify-js-isolation.py` through the
private isolated Python. The fixture executes with the exact provider arguments,
empty stdin and a private TMPDIR. It checks normal evaluation first, then real
attempts to read/write a sibling-directory sentinel, spawn processes, fetch a
loopback HTTP endpoint, enumerate files, read environment variables, load a file
module, use bjson and start a worker. It also rejects unexpected globals,
static imports and the `--std` option. A future runtime restoring these APIs fails.

The stock 0.18.0 negative control succeeded at read/write, process, HTTP,
directory, environment, file-module, bjson and worker operations. Its native
module names are `qjs:std`, `qjs:os` and `qjs:bjson`; bare names fail in this build.
The solver-only build denied every attempt, modified no sibling files and made
zero HTTP requests. All three real downloads above match the earlier Node and
stock runtime SHA-256. Upstream bulk-challenge and cached-player EJS tests pass.

## Source distribution

`Vendor/build/media-tools-sources.tar.xz` contains the exact source archives,
build script, lock manifest, isolation patch/CLI/check/fixture, MIT license and
this document. Release packaging copies it
alongside the signed DMG. It must be published on the same release as the DMG.
The application contains the manifest, build configuration and license texts.

To rebuild from the source archive, extract it, create `Vendor/src/media-tools`,
copy `sources/*` there and run the included script from that directory's parent
repository layout. The included LAME
patch removes an export for the removed
`lame_init_old` API, which otherwise fails current Apple linking. No algorithm
code is changed. All configure options are preserved in the build script.
FFmpeg's expanded configuration is also included with the runtime.

Upstream references: [yt-dlp](https://github.com/yt-dlp/yt-dlp),
[EJS setup](https://github.com/yt-dlp/yt-dlp/wiki/EJS),
[CPython configuration](https://docs.python.org/3.14/using/configure.html),
[FFmpeg licensing](https://ffmpeg.org/legal.html), and
[QuickJS-NG source](https://github.com/quickjs-ng/quickjs/tree/v0.18.0).

## Size measurement

Run `scripts/measure-bundle-size.py /path/to/MacEase.app /path/to/MacEase.dmg`.
The table reports file bytes and allocated bytes (`st_blocks × 512`), without
following symlinks or counting hard links twice. DMG compression is shared across
components; only its total has an unambiguous compressed size. APFS clone sharing
and filesystem metadata are outside these file-level measurements.
