## Performance observations

The signed Release app edited a 24-megapixel 6000x4000 JPEG and a 3840x2160
video. Three continuous photo-slider drags completed in approximately 1.6 s
including automation overhead; the interface remained responsive. A 15-minute
RSS sample contained 3,458 observations, peaked at 355.94 MiB and ended at
201.89 MiB. Intermediate closed-editor observations were approximately 229,
203, 188 and 222 MiB. Repeated photo/video opening and closing did not show
monotonic retained growth in this session. These are warm-process observations,
not a universal memory or latency guarantee.

## Limits and exclusions

- UNVERIFIED, OWNER-EXCLUDED: actual VoiceOver operation and macOS 26 VM visual
  interaction. Accessibility labels and physical macOS 27 checks do not replace
  those checks.
- Animated/multipage photos are rejected. RAW editing uses the decoded image
  and derives a supported output instead of replacing the RAW original.
- HDR color edits always derive SDR. Unsupported HDR geometry conversions are
  refused or require a new SDR file, as described before Save.
- Audio speed/volume conversion supports mono and stereo; unsupported channel
  layouts fail explicitly, retaining the source.
- No exhaustive every-format/every-control cross-product is claimed.
- The existing self-signed release certificate is retained; Apple notarization
  is outside the existing release process.
